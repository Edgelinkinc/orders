Processing an Order

The whole job happens in one panel. Everything you enter updates every tab at once.

  1. Find the orderGo to All Orders and use the search box — it matches store, employee, NTID, order ID or PO number. The filters narrow by status, tracking state and store. Click View on the row.
  2. Add purchasing detailsIn the 🔒 Admin Only panel, enter the Purchase Order # and Cost. Cost is what drives every spend figure on the Analytics tab, so put it in even if the order is small.
  3. Add trackingPick the carrier and paste the tracking number. For a split shipment, hit + Add tracking # for each box — or paste all the numbers at once and they'll fill separate rows automatically, one per line.
  4. Set the two statusesTracking Status is where the boxes are. Order Status is whether you're done with it. They're independent — see the table below.
  5. Save & Update All TabsOne click writes to SharePoint and refreshes every view. If the status changed, this is also what sends the store their email.

The Two Statuses

They mean different things and they don't move together. Setting them correctly is what keeps Analytics honest.

Tracking StatusUse it when
PendingOrder received, nothing shipped yet. This is where every new order starts.
In TransitIt's shipped and there's a tracking number. Counts toward Pending Cost.
Partially DeliveredSome boxes arrived, others still moving.
DeliveredEverything arrived. Only Delivered orders with a cost count as spend.
Order Status is separate: Pending means you haven't finished processing it, Fulfilled means you have. An order can be Fulfilled and still In Transit — that's normal and correct.

What Sends an Email

Stores are notified automatically. You never send anything by hand.

TriggerWho gets it
Tracking Status changesStore email in To, manager and coach in CC — all read from the EdgeLink Store Roster.
Order Status becomes Fulfilled
A new tracking number is added
Editing a PO or fixing a cost sends nothing. If two things change in one save, the store gets one email covering both, not two. Removing a tracking number sends nothing — if you emailed a wrong number, tell the store directly.

If Something Looks Wrong

An edit didn't stickHit Refresh in the top bar. If it's still wrong, the Power Automate flow run history will show what the save actually sent.
A store didn't get its emailCheck that store has a Store Email in the roster. No address means the email is skipped silently.
The catalog looks staleReps' browsers cache the form. A hard refresh (Ctrl+Shift+R) picks up catalog changes.
You can't edit anythingYour HQ user record doesn't have admin-edit rights. Another admin can toggle it under HQ Users.
